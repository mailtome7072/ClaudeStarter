# 코드 리뷰 지침

## 코드 리뷰 원칙

- sprint-close agent의 4단계, hotfix-close agent의 3단계에서 체크리스트를 실행한다.
- 보안 → 성능 → 코드 품질 → 테스트 → 패턴 준수 순서로 검토한다.
- 체크리스트 완료 후 결과를 DEPLOY.md에 기록한다.
